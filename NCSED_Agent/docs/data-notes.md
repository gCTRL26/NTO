## World Bank

Схема одинакова во всех файлах:

```
indicator_id | indicator_name | country_id | country_name | countryiso3code
             | date | value | unit | obs_status | decimal
```

### Ловушки

| Что | Факт | Последствие |
|---|---|---|
| `unit` | **пуст во всех 29 470 записях** | README его обещает. Единицу измерения взять неоткуда; выводить из названия ненадёжно (см. долг Д1) |
| `sourceNote` | пуст у **14 759 из 29 416** | у половины индикаторов поисковый текст — это только название и тема |
| `topics` | заполнены у **5 582 из 29 470** (19%) | таксономия из 21 темы есть, но опираться на неё нельзя |
| `sourceOrganization` | пуст у половины | `publisher` обязан быть `\| None` |
| `date` | у **28% файлов это строка**, а не число: `2020Q3`, `2011-21S`, `2012 Target` | `int(date)` падает. Год извлекается из первых 4 символов через `pd.to_numeric(..., errors="coerce")` |
| `countryiso3code` | **пуст у 47% файлов, где данные есть** | подсчёт географии по нему даёт неверный ноль почти для половины каталога. Считать по `country_id` |
| Разреженность | в среднем больше половины ячеек пусты | это **норма**, а не поломка: файл — декартово произведение стран и лет. Долю пустых мерить бессмысленно, важно покрытие конкретного среза |
| Индикаторы без файла | 1 902 (по факту сборки) | основной источник статуса «Нет файла» |
| Файлы без описания | 97 | |
| Полностью пустые файлы | 229 из 29 470 | например `C1.11b` — «World Bank funding page» |
| `country_id` | пуст во **всех** строках у 266 файлов с данными | например `BPK.AUD.SUBN`. Даёт `n_geo_units = 0` при наличии данных. Меньше, чем было с `countryiso3code` (47%), но не ноль |
| **Два способа кодировать страну** | у файлов WDI `country_id` — внутренний код (`ZH`, `1A`), а ISO3 лежит в `countryiso3code`; у остальных наоборот — ISO3 прямо в `country_id`, а `countryiso3code` пуст | **ни одна колонка по отдельности страну не определяет.** Для проверки покрытия брать `countryiso3code`, при пустом — `country_id`. Фильтр только по одной колонке молча даёт «данных по России нет» там, где они есть |
| Узкие поднаборы | `IE.ICT.TOTL.CD` — 70 строк по десятку стран Африки за 2003–2009, хотя называется «ICT expenditure» | название индикатора ничего не говорит о его охвате. Отсюда необходимость проверять покрытие открытием файла |
| Субнациональные наборы | есть: `SP.POP.TOTL.ZS` — 2033 гео-единицы, серия `SN.SH.STA.*` — «Sub-National…» | **ломает допущение, что у World Bank всегда уровень «Страны мира»** (долг Д6) |
| Прогнозы вместо наблюдений | `CC.ADPO.MAEX.AA` содержит только 2100 год, `CC.ADPO.MIEX.*` — только 2050 | это климатические проекции, а не измерения. Год 2100 в каталоге — не ошибка разбора |

### Периодичность

В метаданных её нет, но она выводится из типа колонки `date`: целое число —
годовые данные, `2020Q3` — квартальные. README об этом молчит.

## ЕМИСС (Росстат)

Метаданные богатые — 13 полей, включая методологические пояснения, ведомство,
периодичность и список измерений. Данные при этом сырые.

### Формат данных: выгрузка Excel, а не таблица

```
column00          column01                  column03            column06  column07
Виды показателя   Виды рынков               Единица измерения   2000.0    2001.0    <- ЗАГОЛОВОК в строке 0
30 К соотв. пер.  3 Вторичный рынок жилья   744 процент         NaN       NaN
```

Четыре проблемы:

1. Колонки называются `column00…columnNN`; настоящие имена лежат в строке 0.
2. Широкий формат: **годы разнесены по колонкам**, а не по строкам.
3. В ячейках код классификатора слипся с названием: `"643 Российская Федерация"`,
   `"384 тысяча рублей"`, `"54 I квартал"`.
4. Схема разная в каждом файле — от 5 до 60 колонок, разный набор измерений.

Поэтому `pd.read_parquet(columns=[...])` здесь не работает: имена колонок
бессмысленны, файл читается целиком.

Папка `clean_jsonl/` содержит уже нормализованный длинный формат — но только
для **84 показателей из 7 328**.

### Ловушки

| Что | Факт | Последствие |
|---|---|---|
| Персональные данные | поле «Ответственный» содержит ФИО, рабочий телефон и почту сотрудников Росстата — во всех 7 330 файлах | не индексировать, не отправлять в LLM. Вырезается в `fedstat.iter_metadata` |
| `indicators.csv` vs `metadata/` | 8 718 против 7 330 | **1 480 кодов не имеют метаданных вообще** — карточку из них не построить, в каталог не попадают |
| `metadata/` vs `parquet/` | 7 330 против 7 328 | реальных случаев «описание есть, данных нет» всего **2** (`31041`, `31138`) |
| `invalid_files.json` | 14 кодов | файлы есть, но не разбираются — отсюда статус «Файл есть, но не читается» |
| Единицы измерения | приходят как `"* тысяча квадратных метров общей площади"` — со звёздочкой | чистить при разборе |
| «Размещение» | это раздел сайта, а не тема: `"Ввод в действие жилых домов "` (с хвостовым пробелом) | тематики у ЕМИСС нет, использовать как `theme` — натяжка |
| «Длина временного ряда» | заявленный период (`"2000 - 2025"`), а не реальный | `real_year_*` обязан считаться по файлу, иначе система повторяет обещание источника |
| **Заявленный разрез ≠ реальный** | у **15%** показателей ОКАТО есть среди «Признаков», но в данных заполнен единственным значением «643 Российская Федерация» | метаданные обещают разбивку по субъектам, которой в файле нет. Примеры: `30946`, `60802`, `57401`, `58714`. Поэтому `level` считается по `n_geo_units` из данных, а метаданные — только запасной вариант |
| Строка-заголовок | отсутствует примерно у **3%** файлов: строка 0 уже содержит данные | без подписей нельзя понять, где годы. Статус «Файл есть, но не читается» — честнее, чем угадывать |
| Размер файлов | медиана 109 строк и 12 колонок, но встречаются до 1.5 млн строк и 38 колонок | читаем целиком (выбрать колонки заранее нельзя), выбросы редки |
| `url` | есть только в `metdata.csv` (6 905 строк), в JSON-метаданных нет | ссылка конструируется из кода: `https://www.fedstat.ru/indicator/{code}`. `metdata.csv` не нужен |

## Замеры производительности

| Операция | Время |
|---|---|
| `worldbank.iter_metadata()` — 29 470 записей | 0.3 с |
| `fedstat.iter_metadata()` — 7 330 файлов | 2.5 с (первый запуск на холодном кэше ФС заметно дольше) |
| `worldbank.scan_file()` — выборка 400 файлов | 10 мс на файл |
| `worldbank` — **полный скан 29 470 файлов** | **840 с ≈ 14 мин**, то есть 28.5 мс на файл |
| `build` поверх готового кэша | секунды |
| `fedstat.scan_file()` — выборка 250 файлов | 28 мс на файл |
| `fedstat` — **полный скан 7 330 файлов** | **434 с ≈ 7.2 мин**, то есть 59 мс на файл |

**Замеры на выборке оказались оптимистичнее реальности в обоих случаях** — World Bank
втрое (10 против 28.5 мс), ЕМИСС вдвое (28 против 59 мс). Причина одна: файлы выборки
уже лежали в кэше файловой системы после предыдущих прогонов. Холодный полный обход
упирается в диск, а не в разбор parquet.

Урок: **бенчмарк на прогретом кэше врёт, и врёт систематически в одну сторону.**
Для честной оценки нужен либо холодный запуск, либо поправка на ввод-вывод в 2–3 раза.

Вывод по существу не изменился: около 21 минуты один раз при построении кэша —
терпимо, параллельность не нужна.

## Долги

| # | Что | Почему отложено |
|---|---|---|
| Д1 | `unit` для World Bank всегда `None` | Можно парсить из названия: `GDP (current US$)` → доллары. Но `Unemployment, total (% of total labor force) (modeled ILO estimate)` — две скобки, последняя не единица. Наивный разбор наврёт, а по ТЗ соврать хуже, чем промолчать. Сначала замерить, у скольких названий скобка реально содержит единицу |
| Д2 | `periodicity` для World Bank всегда `None` | Выводится из типа колонки `date`, но это факт из файла — место ему в `FileFacts`, а `scan_file` его пока не считает |
| Д3 | Битые файлы метаданных пропускаются молча | `continue` без следа. Если завтра развалится тысяча файлов, каталог просто станет меньше и никто не заметит. Нужен счётчик и запись в лог, когда появится слой `obs/` |
| Д4 | `DATA_ROOT` — константа в коде | Должна жить в настройках рядом с `LLM_BASE_URL` |
| Д5 | Нормализация ЕМИСС не написана | `fedstat.scan_file` и приведение широкого формата к длинному — Ф2c |
| Д6 | `level` у World Bank жёстко «Страны мира» | Неверно для субнациональных наборов (`SP.POP.TOTL.ZS` — 2033 гео-единицы, серия `SN.SH.STA.*`). Дешёвая эвристика: если гео-единиц заметно больше 300, это не страновой уровень. Требует расширения `Literal` в `DatasetCard` |

## Общие уроки

- **README источника — это гипотеза, а не факт.** `unit`, `countryiso3code`
  и тип `date` у World Bank описаны иначе, чем есть на самом деле.
- **Поле, про которое написано «может быть null», однажды окажется null
  у половины данных.**
- **Три ручных тест-кейса проверяют логику, прогон на выборке проверяет
  предположения о данных.** Второе всегда находит неожиданное.
