# Helper Agent — виртуальный специалист по данным

Прототип ИИ-ассистента для НЦСЭД: пользователь описывает задачу на естественном
языке, система проходит полный цикл работы data-специалиста и отдаёт готовый
датасет со скриптом сборки и ссылками на источники.

> Статус: в разработке. Раздел «Запуск» дополняется по мере готовности.

## Принципы

1. **Числа извлекает код, не модель.** LLM отвечает за понимание запроса,
   маршрутизацию и формулировки. Значения из файлов достаёт детерминированный
   Python, в том числе сгенерированный.
2. **Факт без ссылки на источник — ошибка.** Если данных нет, система говорит
   об этом и объясняет почему, а не придумывает правдоподобное значение.
3. **Ценность на каждом шаге.** Пользователь может забрать промежуточный
   артефакт и уйти, попросить правку или сменить направление.

## Пользовательский путь

| # | Шаг | Артефакт |
|---|-----|----------|
| 1 | Запрос на естественном языке | — |
| 2 | Определение исследования | `ResearchDefinition` |
| 3 | Дизайн исследования | `ResearchDesign` |
| 4 | Структура целевого датасета | `TargetDatasetSchema` |
| 5 | Поиск и план сборки | `BuildPlan` |
| 6 | Генерация скрипта | `GeneratedScript` |
| 7 | Сборка датасета | `DatasetArtifact` |

## Структура

```
helper_agent/
├── domain/     контракты артефактов (pydantic)
├── llm/        клиент, structured output, промпты
├── catalog/    реестр датасетов, гибридный поиск
├── graph/      StateGraph: узлы, рёбра, чекпойнты
├── guards/     гардрейлы: grounding, инъекции, ресурсы
├── codegen/    генерация скрипта сборки
├── sandbox/    изолированное исполнение скрипта
├── ui/         чат на Streamlit
└── obs/        логи, трейсинг, метрики
evaluation/     тест-кейсы и метрики качества
docs/adr/       архитектурные решения и их обоснование
```

## Архитектура

Кратко: граф с фиксированными стадиями, ReAct-цикл вложен в узел поиска
источников. Обоснование и рассмотренные альтернативы — в
[ADR-001](docs/adr/001-workflow-with-nested-agent.md).

Два профиля LLM — облачный API для разработки и Ollama для запуска на GPU;
переключение через `.env`. См. [ADR-002](docs/adr/002-llm-provider-abstraction.md).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Дальше заполнить `.env`. Команда запуска появится после Ф7.
